١) الاتصال وتسجيل الدخول (كأدمن)

أدخل إعدادات مشروعك ثم سجّل الدخول بحساب تريد جعله أدمن. القيم معبّأة بإعدادات تطبيقك الحالي — غيّرها إن أنشأت مشروعاً جديداً.

نطاق البريد الافتراضي للتطبيق: @wachat.app (يُضاف تلقائياً إن أدخلت اسم مستخدم فقط).

٢) تفعيل صلاحيات الأدمن الكاملة

القواعد الحالية تمنعك من حذف بيانات مستخدم آخر. لتحصل على تحكّم كامل، انسخ القاعدة التالية والصقها في:
Firebase Console → Realtime Database → Rules → Publish.
